# Guide

Nanofile is one binary that speaks the Seafile sync protocol and serves its own
web interface. This guide walks from the first run to running it for a long
time: installing it, connecting clients, configuring it, administering accounts
and keeping it healthy.

The pages are grouped into five chapters. Each page is self-contained and links
to the pages it depends on.
