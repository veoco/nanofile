# 账号安全

账号自己的设置在**设置 → 安全**与**设置 → 会话与凭据**两页。服务端侧的凭据规则在[安全](/zh/guide/security)。

## 两步验证（TOTP）

在**设置 → 安全**开启：

1. 点两步验证下的**设置**，页面给出二维码。
2. 用验证器 App 扫描；扫不了就手动输入下面那串密钥。
3. 输入验证器上的 6 位码完成确认。
4. **把备用码存好**——它只显示一次，用于在拿不到验证器时登录。

关闭两步验证需要输入当前密码。

登录时先输密码，再输 6 位码。勾选"信任此设备"后，这台设备 **90 天**内不再询问——同步客户端也是同一套机制，见[客户端接入](/zh/guide/clients)。动态口令同样有尝试次数上限（`auth.totp_max_attempts`）。

## 会话与凭据

**设置 → 会话与凭据**把账号名下所有能进入服务器的凭据分组列出，每一条都能单独吊销：

| 分组 | 内容 |
|---|---|
| 客户端设备 | 每台设备的平台、名称与上次登录；展开可见它的会话、同步令牌与受信状态，也可整台解绑。 |
| 浏览器会话 | 每次网页登录，**当前会话**会标出来；可逐条吊销，也可以一次"退出其他所有会话"。 |
| 同步令牌 | 客户端持有的令牌，快过期的会标记出来。 |
| 受信设备 | 两步验证的信任记录，带到期时间。 |
| API 密钥 | 数量与入口，管理页在**设置 → API 密钥**。 |

认不出某台设备就吊销它——吊销不删数据，只是让那条凭据立刻失效。

## 密码

改密码需要当前密码。忘记密码时：

- 邮件可用的话用登录页的"忘记密码"拿重置链接（`auth.enable_password_reset`，每小时有次数上限）；
- 管理员也可以在服务器上用 `nanofile adduser` 另建一个管理员，再从网页里处理，见[命令行](/zh/reference/cli)。

密码策略（`auth.password_min_length`、`auth.require_strong_password`）与登录失败锁定（`auth.max_login_attempts`、`auth.lockout_duration_secs`）由管理员在**系统设置 → 身份验证 / 速率限制**里设置。

## 什么操作会吊销什么

| 操作 | 影响范围 |
|---|---|
| 改密码 | 该账号**其他设备**的会话、全部同步令牌、全部 API 密钥 |
| 停用账号 / 远程擦除 | 该账号持有的全部登录，包括尚未使用的密码重置链接 |
| 在"会话与凭据"里吊销一条 | 只有那一条失效 |
| 更换主密钥 `server.secret_key` | 所有人：会话登出、同步客户端失效、已加密的块解不开（见[安全](/zh/guide/security)） |

## API 密钥

API 密钥让第三方工具——WebDAV 客户端、同步客户端、脚本——无需共享账号密码即可接入。密钥只携带被授予的能力，并可进一步限制到特定资料库；密钥管理界面本身只接受浏览器会话，因此密钥不能再签发密钥。

创建与用法见[客户端接入](/zh/guide/clients)。

## 登录提醒

邮件配置好之后，服务器会为新设备/新浏览器登录、以及新建 API 密钥发送提醒。见[邮件通知](/zh/guide/email)。
