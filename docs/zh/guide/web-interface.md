# 网页界面

登录后首先看到的是文件管理界面。本页按界面自身的结构走一遍：左侧栏、资料库、文件浏览，然后是收藏、分享、回收站、动态、搜索与个人设置。管理员还能进管理后台，见[配置](/zh/guide/configuration)与[用户与分享](/zh/guide/users-and-sharing)。

## 界面骨架

- **左侧栏** —— 上半是资料库树（带过滤框，只对这一份列表生效），下半是「浏览」：收藏、分享、回收站、动态。底部是账号的空间用量条与版本号。
- **顶栏搜索框** —— 回车跳到搜索页，见[搜索](#搜索)。
- **右侧详情抽屉** —— 选中一条记录后从底部升起，见[文件浏览](#文件浏览)。

| 快捷键 | 作用 |
|---|---|
| `/` | 聚焦搜索框 |
| `g` 然后 `l` | 资料库列表 |
| `g` 然后 `s` | 收藏 |
| `g` 然后 `t` | 回收站 |
| `g` 然后 `a` | 动态 |
| `g` 然后 `p` | 个人设置 |

## 资料库

`/libraries/` 列出你有权限的资料库，可按名称、修改时间、大小排序，也可过滤。

- **新建资料库** 在页头。网页创建的是**普通资料库**；**加密资料库由客户端创建**（列表里带锁标记），它的密码只在客户端输入，服务端无法代填。
- 每行的 **⋯** 菜单里有**编辑**：改名称与描述，设置**历史保留**（最多保留多少个版本、最多保留多少天），以及查看该库的 WebDAV 地址。
- 删除资料库后进入回收站的「资料库」标签，不是立刻消失。

## 文件浏览

进入 `/libraries/<库 id>/files/` 就是文件管理器。

### 三种视图

- **列表** —— 名称、大小、修改时间。
- **网格** —— 带缩略图的方块。
- **画廊** —— 按月份分组的图片与视频（纯音频不会出现在画廊里，但在列表和网格中照常可见）。

### 上传

工具栏有**新建文件夹**、**上传文件夹**、**上传文件**；也可以把文件或文件夹**拖到列表区域**，松手即上传到当前目录。上传过程中右下角有进度面板，可以最小化，上传继续。

### 每一行的操作

行末 **⋯** 菜单（或在详情抽屉里）：

- **分享链接** / **上传链接** —— 创建与改密码，见[用户与分享](/zh/guide/users-and-sharing)。
- **下载** —— 文件直接下载；文件夹打包成 zip。
- **历史** —— 文件的版本历史，可查看此前的版本。
- **重命名**、**删除**。

选中多条时，详情抽屉给出批量**下载、移动、复制、重新索引、删除**。

### 详情抽屉

选中一条记录后从底部展开。除类型、大小、修改时间外还有：

- **星标** —— 加星的条目出现在「收藏」页。
- **标签** —— 自己加的文字标签。
- **EXIF** —— 照片的拍摄信息。
- **全文索引** —— 该文件被索引出的正文，以及「重新索引」按钮；没被索引时这里会说明原因。
- **分享链接 / 上传链接** —— 这个文件已发出的链接。

### 预览

双击一行（或详情抽屉里的预览）弹出快速预览：图片、音视频、以及文本类文件（含代码、配置、CSV、日志等）都能直接在浏览器里看。浏览器渲染不了的类型（例如 PDF 与 Office 文档）会给出下载入口，不假装能预览——但它们的正文仍会被索引，因此可以在搜索里被找到。

## 收藏

`/starred/` 列出所有加星的文件与文件夹。星标是每人一份的，不影响他人。

## 分享

`/shares/` 分两个标签：**分享链接**（别人下载）与**上传链接**（别人上传）。每条可以改密码（保留原密码 / 换新 / 去掉）、改过期时间（1/7/30 天，或清除过期）、改说明，也可以删除。

## 回收站

`/trash/` 同样分两个标签：

- **文件** —— 删掉的文件，可搜索、可**还原**、可**清空回收站**。
- **资料库** —— 整个资料库，可**还原**或**彻底删除**。

清空是彻底的：还原不了的不要点。

## 动态

`/activities/` 是服务器上发生的事：新增、修改、重命名、移动、删除，按时间倒序，点条目可以跳回它所在的资料库与目录。

## 搜索

`/search/` 有两种范围：

- 默认**搜文件名也搜正文**——正文来自索引器提取的文本，PDF 与 Office 文档因此也能被搜到，结果里会显示命中片段。
- 勾选**仅文件名**后只匹配名字。

结果往下滚动会继续加载。搜不到东西时先确认索引是开着的：见[维护与故障排查](/zh/guide/maintenance)。

## 个人设置

`/settings/` 下的页面：

| 页面 | 用途 |
|---|---|
| 总览 | 账号信息 |
| 资料 | 昵称、头像、语言等 |
| 安全 | 两步验证、密码 |
| 会话与凭据 | 登录过的设备、同步令牌、吊销 |
| API 密钥 | 为第三方工具签发密钥，含 WebDAV 密钥 |
| 邀请码（管理员） | 生成注册邀请码 |

两步验证与凭据的细节见[账号安全](/zh/guide/account-security)。
