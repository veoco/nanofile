# 网页界面

登录后首先看到的是文件管理界面。本页是界面骨架、资料库列表和主要浏览区域的导览。上传、移动、版本、分享和回收站操作见[文件与分享](/zh/guide/use/files-and-sharing)。

**适合谁：** 使用浏览器界面的用户。**前置条件：** 一个账号，以及对至少一个资料库的读权限。

## 界面骨架

- **左侧栏** —— 上半是资料库树（带过滤框，只对这一份列表生效），下半是「浏览」：收藏、分享、回收站、动态。底部是账号的空间用量条与版本号。
- **顶栏搜索框** —— 回车跳到搜索页，见[搜索](#搜索)。
- **详情抽屉** —— 选中一条记录后从底部升起，见[文件浏览](#文件浏览)。

管理员还会在用户菜单里看到**系统设置**入口；管理后台见[配置](/zh/guide/configure/configuration)与[用户与分享](/zh/guide/admin/users-and-sharing)。

## 资料库

`/libraries/` 列出你有权限的资料库，可按名称、修改时间、大小排序，也可过滤。

- **新建资料库**在页头。网页创建的是**普通资料库**；**加密资料库由客户端创建**（列表里带锁标记），它的密码只在客户端输入，服务端无法代填。
- 每行的 **⋯** 菜单里有**编辑**：改名称与描述，设置**历史保留**（最多保留多少个版本、最多保留多少天），以及查看该库的 WebDAV 地址。
- 删除资料库后进入回收站的「资料库」标签，不是立刻消失。

## 文件浏览

进入 `/libraries/<库 id>/files/` 就是文件管理器。

### 视图

- **列表** —— 名称、大小、修改时间。
- **网格** —— 带缩略图的方块。
- **画廊** —— 按月份分组的图片与视频。纯音频没有缩略图，因此不出现在画廊里，但在列表和网格中仍然可见。

### 预览

双击一行，或在详情抽屉里预览，打开快速预览：图片、音频、视频和文本类文件（源代码、配置、CSV、日志）直接在浏览器里渲染。浏览器渲染不了的类型（例如 PDF 与 Office 文档）给下载入口，不做假预览；但它们的正文仍会被索引，因此可以在搜索里被找到。

选中一条记录后，**详情抽屉**从底部展开。除类型、大小、修改时间外还有：

- **星标** —— 加星的条目出现在「收藏」页。
- **标签** —— 自己加的文字标签。
- **EXIF** —— 照片的拍摄信息。
- **全文索引** —— 该文件被索引出的正文，以及「重新索引」按钮；没被索引时这里会说明原因。
- **分享链接 / 上传链接** —— 这个文件已发出的链接。

抽屉里不放内联播放器：摘要行的缩略图就是静帧，视频和音频都用快速预览播放。上传、移动、版本和创建链接见[文件与分享](/zh/guide/use/files-and-sharing)。

## 收藏

`/starred/` 列出所有加星的文件与文件夹。星标是每人一份的，不影响他人。

## 分享

`/shares/` 分两个标签列出你创建的链接：**分享链接**（别人下载）与**上传链接**（别人上传）。可以改密码、过期时间或说明，也可以删除。见[文件与分享](/zh/guide/use/files-and-sharing#管理已有链接)。

## 回收站

`/trash/` 分两个标签：

- **文件** —— 删掉的文件，可搜索、可**还原**、可**清空回收站**。
- **资料库** —— 整个资料库，可**还原**或**彻底删除**。

清空是彻底的：还原不了的不要点。具体操作见[文件与分享](/zh/guide/use/files-and-sharing#版本与回收站)。

## 动态

`/activities/` 是服务器上发生的事：新增、修改、重命名、移动、删除，按时间倒序，点条目可以跳回它所在的资料库与目录。

## 搜索

`/search/` 有两种范围：

- 默认**搜文件名也搜正文**——正文来自索引器提取的文本，PDF 与 Office 文档因此也能被搜到，结果里会显示命中片段。开启 `[ocr]` 后，图片和没有文本层的 PDF 页中识别出的文字也属于正文；见[图片与 PDF 文字识别](/zh/guide/use/ocr)。
- 勾选**仅文件名**后只匹配名字。

结果往下滚动会继续加载。搜不到东西时先确认索引是开着的：见[维护](/zh/guide/operate/maintenance)。

## 个人设置

`/settings/` 下的页面：

| 页面 | 用途 |
|---|---|
| 总览 | 账号信息 |
| 资料 | 昵称、头像、语言等 |
| 安全 | 两步验证、密码 |
| 会话与凭据 | 登录过的设备、同步令牌、吊销 |
| API 密钥 | 为第三方工具签发密钥，含 WebDAV 密钥 |
| 邀请码（管理员） | 生成注册邀请码 |

两步验证与凭据的细节见[账号安全](/zh/guide/use/account-security)。

## 快捷键

| 快捷键 | 作用 |
|---|---|
| `/` | 聚焦搜索框 |
| `g` 然后 `l` | 资料库列表 |
| `g` 然后 `s` | 收藏 |
| `g` 然后 `t` | 回收站 |
| `g` 然后 `a` | 动态 |
| `g` 然后 `p` | 个人设置 |
