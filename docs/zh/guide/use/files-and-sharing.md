# 文件与分享

本页讲文件管理器本身：把文件传进传出、整理、恢复，以及创建分享链接或上传链接。外围界面见[网页界面](/zh/guide/use/web-interface)。

**适合谁：** 已登录网页界面的用户。**前置条件：** 上传、移动、删除和创建链接需要对资料库有读写权限；只读资料库仍然可以下载。

## 上传与下载

### 上传

- 用工具栏的**上传文件**、**上传文件夹**或**新建文件夹**。
- 也可以把桌面上的文件或文件夹**拖到文件列表**上，松手后上传到当前目录。
- 右下角会打开进度面板，上传期间可以最小化。

### 下载

- 文件直接下载。
- 文件夹打包成 zip 下载。
- 想下载多个条目，选中后在详情抽屉里点**下载**。

## 视图与预览

文件浏览器有三种视图：

- **列表** —— 名称、大小、修改时间。
- **网格** —— 带缩略图的方块。
- **画廊** —— 按月份分组的图片与视频。纯音频没有缩略图，因此不出现在画廊里，但在列表和网格中仍然可见。

双击一行，或在详情抽屉里点**预览**，打开快速预览。图片、音频、视频和文本类文件（源代码、配置、CSV、日志）直接在浏览器里渲染。PDF 与 Office 文档给下载入口，不做假预览；但它们的正文仍会被索引，可以搜索。

## 整理文件

- 行末 **⋯** 菜单里有**重命名**和**删除**。
- 选中多个条目可以批量**下载**、**移动**、**复制**、**重新索引**或**删除**。
- 详情抽屉显示类型、大小、修改时间、星标、标签、EXIF 和提取出的全文索引，还带单个文件的**重新索引**按钮。
- 删除文件只是把它移进回收站，不会立刻释放块。垃圾回收见[维护](/zh/guide/operate/maintenance)。

## 版本与回收站

- 文件上的**历史**打开版本历史，可以查看此前的版本。
- **回收站 → 文件**存放已删除文件，可搜索、可还原，也可以**清空回收站**。
- **回收站 → 资料库**存放整个被删的资料库，可以还原或彻底删除。

清空是彻底的。先还原，或者在清空前下载一份副本。

## 分享链接

分享链接让没有账号的人下载一个文件或文件夹。

1. 选中文件或文件夹，在行菜单或详情抽屉里选**分享链接**。
2. 设置密码、过期时间（也可以不过期），分享链接还可以设置查看次数。
3. 复制链接并发送。

链接打开一个公开页面，展示文件或文件夹。带密码的链接先要求输入密码；过期或用完的链接会显示为已失效。

## 上传链接

上传链接让没有账号的人向当前资料库和目录上传。创建方式与分享链接相同，把链接发出去即可，收件人不需要 Nanofile 账号。

- 上传链接支持密码和过期时间。
- 不能指向加密资料库。服务器没有该资料库的密码，无法写入上传内容。
- 管理员关闭上传分享之前创建的上传链接，在使用时会被拒绝。

## 管理已有链接

左侧栏的**分享**分两个标签列出你创建的链接：**分享链接**与**上传链接**。每条链接都可以：

- 保留、替换或去掉密码；
- 修改或清除过期时间（1、7、30 天，或不过期）；
- 修改说明；
- 删除。

管理员可以在**系统设置 → 分享管理**看到所有用户的链接，并删除失效的。关闭下载分享或上传分享的开关在**系统设置 → 安全 → 分享功能**；见[用户与分享](/zh/guide/admin/users-and-sharing#sharing-policy)。

## 验证

- 在隐私窗口打开一个新分享链接，确认密码提示和下载都正常。
- 在隐私窗口打开一个上传链接，上传一个小文件，确认它出现在目标目录。
- 删除一个测试文件，从**回收站 → 文件**还原，再下载一次。
