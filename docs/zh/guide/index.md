# 指南

Nanofile 是一个二进制：既实现 Seafile 同步协议，又提供自己的网页界面。本指南从首次运行讲到长期运维——安装、接入客户端、配置、管理账号，以及保持它健康运行。

页面按五章组织，每页自成一体，只链接它依赖的页面。
